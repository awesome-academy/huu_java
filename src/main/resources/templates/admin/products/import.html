Import Sản Phẩm từ Excel

Quay lại
1. Tải file mẫu

File mẫu có sẵn các cột Tên, Danh mục, Loại, Giá, Mô tả, Còn bán, kèm sheet hướng dẫn và danh sách danh mục hiện có.

Tải file mẫu (.xlsx)
2. Tải file lên
Quy tắc
  • Chỉ nhận file .xlsx, tối đa 5 MB và 1000 dòng dữ liệu; chỉ sheet đầu tiên được đọc.
  • Mỗi dòng được kiểm tra như khi thêm sản phẩm bằng form; danh mục phải có sẵn.
  • Tên trùng chính xác một sản phẩm đã có → cập nhật sản phẩm đó (danh mục, loại, giá, mô tả, còn bán; ảnh giữ nguyên). Tên chưa có → thêm mới.
  • Tên chỉ khác chữ hoa/thường hoặc dấu so với sản phẩm đã có → báo lỗi, không tự cập nhật.
  • Có một dòng lỗi thì không dòng nào được lưu — sửa file rồi import lại.
  • File được xử lý nền: sau khi tải lên bạn được chuyển tới trang trạng thái, trang tự cập nhật tới khi xong (kết quả hoặc bảng lỗi theo dòng).
